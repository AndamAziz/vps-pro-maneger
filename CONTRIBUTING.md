# Contributing to VPS Manager Pro

Thank you for your interest! 🎉

## How to Contribute

1. Fork the repository
2. Create a feature branch
3. Make your changes
4. Test thoroughly
5. Submit a pull request

## Code Style

- Follow PEP 8
- Use type hints
- Write docstrings
- Add logging
- Handle errors

## Commit Messages

Format: `<type>(<scope>): <subject>`

Types:
- feat: New feature
- fix: Bug fix
- docs: Documentation
- refactor: Code refactoring

## Pull Request Process

1. Update documentation
2. Test your changes
3. Follow coding standards
4. Write clear commit messages
